# 超级爱使用手册

[English](index.en.md)

超级爱把网页播放器、私人曲库和小爱音箱接入同一个自托管平台。可以只在浏览器听歌，也可以连接音箱后使用投放、语音点歌和 AI 问答。

## 从部署到第一次播放

1. 用 Docker、Docker Compose 或 Node.js 启动服务，打开部署机的 `http://localhost:8787` 并初始化管理员。[部署步骤](deployment.md)
2. 选择音乐来源。已有 Navidrome、Subsonic、飞牛音乐或 WebDAV 的用户可接入私人库。使用在线目录时，在播放器导入兼容的 LX 音源。[音乐库与音源](usage.md#连接音乐库和音源)
3. 在播放器搜索并双击一首歌曲，先确认网页能够播放。需要投放时，在「音箱设备」扫码登录小米账号并选择音箱。[网页播放与音箱投放](usage.md#播放与投放)
4. 需要语音点歌和问答时，在「平台设置」测试并保存 AI 模型，再到「音箱设备」开启语音监听。[AI 与语音](usage.md#ai-模型与语音联动)
