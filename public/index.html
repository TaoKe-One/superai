高级：外部搜索服务

音乐服务

同一来源规则用于播放器、语音点歌、歌单和收藏重播。私人库故障会提示错误，不自动改播在线版本。已有队列保留，当前模式不允许的歌曲无法再次起播。

填写部署机器的局域网 IP 和端口，音箱必须能访问。Docker 请使用宿主机 IP 与映射端口；不要填写 127.0.0.1。

私人音乐库

Subsonic/Navidrome 和飞牛直接读取目录。WebDAV 保存后扫描，按文件标签与目录建立索引；文件夹作为虚拟歌单。飞牛填写完整直连地址，暂不支持裸 FN ID。

高级：HTTP JSON / topone 兼容接口

兼容音乐源

音乐源使用固定 HTTP JSON 接口，不执行来源脚本。单曲接口返回 tracks/results/data 曲目数组；需要歌单时另填歌单接口，返回 tracks 数组或包含 playlists 的对象。
